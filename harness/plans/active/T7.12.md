# T7.12 시트 세 묶음 — 지금·다가오는 통제·지난 통제 (태우 11/10 실사용 ②)
- 무엇: 목록 = t 기준 넓은 창 사건(`GET /closures/events?at=t&from=t−365일&to=t+365일`, 상태 t 기준, 지도 응답과 따로 60초 ETag). 세 묶음(0.7 미만은 뺌): 지금(t 가 지금이 아니면 "이 시각") = 통제 중 + 1시간 안 시작, 비면 "지금 서울에 걸린 통제가 없어요" · 다가오는 통제 = 예정·예정 구역을 KST 날짜별(오늘·내일·11월 14일 (토)) · 지난 통제 = 해제, 끝 늦은 순 5개 + "더 보기 (N)". 구 칩은 세 묶음 모두에, 목록과 같이 스크롤(절반 시트에서 목록 자리). 다가오는·지난 행을 누르면 t = 그 시작(지금 모드 끔) + 카드 + 지도 맞춤. t 가 지금이 아니면 시트 위 "M월 D일 HH:MM 기준 · 지금으로 돌아가기", 제목 "서울 통제", 시트 슬라이더의 '지금으로'는 숨김(경로 카드는 그대로)
- 파일: api/naruApiClient.ts(from·to), state/ClosureProvider.tsx(catalog), map/eventKinds.ts(sheetSections), i18n/ko.ts(묶음·날짜·빈 문구), components/LiveSheet.tsx(+css)·TimeSlider.tsx(nowButton), map/MapView.tsx(맞춤에 catalog), scripts/record_live_events.py(넓은 창 기록) + MANIFEST, vitest·e2e
- 검증: 넓은 창 기록 11/7 15:30(지금 12·다가오는 11/9·지난 3/15 마라톤)·11/8 12:00(이 시각 통제 없음 + 내일·지난), 렌더(더 보기·행 → 시각 이동 + 카드·배너 → 지금), 임시 스택 e2e(11/8 12:00 빈 화면 아님 → 지난 r04 → 11/7 15:00 기준·카드 → 지금으로 돌아가기)
