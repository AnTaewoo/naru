## 1. 한 줄 · 문제 · 대상

- **한 줄:** 마라톤·집회·행진으로 막힌 횡단보도를 피해, 지하보도·육교로 건너는 걷는 길을 알려 주는 서비스.
- **문제:** 지도 앱은 도로 통제를 모른다. 통제 정보는 경찰청·서울시(TOPIS) 공지에 글로만 올라온다. 서울 올해 대규모 교통통제 30차례 이상(README 의 기사 링크). 설문 71명 중 69% 가 통제로 길이 막힌 적이 있고, 59% 는 마라톤·집회 때(README 기존 값).
- **대상:** 통제일에 도심을 걷는 사람(시민·관광객), 그리고 통제 데이터를 쓰고 싶은 다른 서비스(공개 피드).
- **범위:** 서울 전체(25개 구). 서울 밖 출발·도착은 "지원 범위 밖".
- **일정:** 2026-11-01 시작 → 11-14 현장 검증(제보 도구) → **11-16 최종 제출**(배포 링크·시연 영상·보고서·포스터) → 11-21 본행사. 2027-03 서울마라톤에서 현장 실증(계획).

## 3. 기능 (사용자 관점, 지금 운영 중인 것)

### 3.1 실시간 통제 지도 (T7.1~T7.5)
- 앱을 열면 그 시각 **서울 전체 통제 사건**이 지도에 뜬다. 60초마다 갱신(ETag, 바뀐 게 없으면 304).
- 줌 3단계: **클러스터**(줌 12 미만) → **통제 구역**(12~15, 사건마다 다각형) → **횡단보도 점**(15 이상).
- 상태 5종을 색으로: 통제 중(빨강) · 1시간 안 시작 · 예정(노랑) · 예정 구역(보라 빗금) · 해제. 위쪽 칩(통제 중 N · 예정 N · 예정 구역 N)이 필터.
- 지하보도 입구는 파랑으로 표시.

### 3.2 시간 바꾸기 (T5.1, T7.11)
- 하단 시트의 **슬라이더**(−10분/+10분 버튼)와 **날짜 선택**(달력)으로 아무 시각의 통제를 본다. "지금으로 돌아가기"로 복귀. 사건 카드를 열어 둔 채로도 슬라이더를 쓸 수 있다.
- 같은 시각·같은 경로를 링크로 공유(`?t=&from=&to=`, `?event=<id>`).

### 3.3 통제 목록 · 사건 카드 (T7.5, T7.12)
- 시트 목록: **지금**(통제 중·1시간 안) · **다가오는 통제**(날짜별) · **지난 통제**(최근 5 + 더 보기). 구(區) 칩으로 거르기.
- 행을 누르면 그 시각으로 가고 지도가 그 구역에 맞춰지며 **사건 카드**: 상태 배지·원인(행진·집회·마라톤)·제목(파서 요약, 예 "시의회~숭례문오거리 → 광화문·고용노동청 행진")·지나는 곳·날짜와 시간 창·**남은 시간**(가장 큰 글자, 예 "15:30 해제 예정")·출처·확신도(말로: 높음/보통 등)·막히는 횡단보도 수·**이 구역 피해서 길찾기**·**통제 근거 보기**(공지 원문).
- 해제 예정 시각이 지나도 30분은 "정리 중"(현장 정리로 막힌 걸로 봄).
- 그 시각 통제가 없으면 "이 시각 서울에 걸린 통제가 없어요" + 예시 버튼 셋(3/15 서울마라톤 07:45 · 11/7 광화문 집회 15:00 · 11/9 국회대로 행진 12:00).
- 실시간 수신이 30분 넘게 멈추면 슬라이더 위에 "통제 정보가 N분째 갱신되지 않았어요" 경고(N 은 실제 경과 시간).

### 3.4 길찾기 (T3, T5.2, T5.5, T5.10, T5.11, T7.6)
- 출발·도착: 검색, 지도 탭(도로명 주소로 표시), **내 위치**.
- **가장 빠른 길**과 **원래 길**(통제를 무시한 길)을 나란히. 원래 길이 막혔으면 "지금 못 감"과 풀리는 시각.
- 경로 상세: 계단·지하보도·육교·횡단보도(교차로 이름)를 구간별로.
- 통제는 **그 횡단보도에 도착하는 시각** 기준(걸어가는 동안 시작·해제되는 것까지 반영). 걷는 속도 초속 1.2 m.
- **이 구역 피해서 길찾기**: 사건 카드에서 그 사건 횡단보도를 시각·확신도와 상관없이 막고 길을 다시 찾는다.
- 규칙(§4.4)은 README 기존 "길찾기" 절과 같음 — 단 **행진도 사건 전 구역을 통제 시간 내내** 막는 것으로 확정(11/12).

### 3.5 장소 검색 · 장소 카드 (T5.8, T7.14, 11/11 수정)
- 맨 위 검색창(카카오 로컬). **지도 가운데 5 km 안 결과 5개를 먼저**, 나머지는 **서울 전체**에서 채움(최대 10). 줄마다 지도 가운데부터 거리.
- 결과를 누르면 지도가 그리로 이동(줌 17) + 이름 핀 + **장소 카드**: 이름·도로명 주소·[출발] [도착] [☆ 저장]·**[☆ 이 근처 알림 받기]**.
- ☆ 저장은 이 기기에만(빈 검색창을 누르면 저장한 장소 목록).

### 3.6 행진 예상 위치 (T7.16, ADR-015)
- 경로·시작·끝이 다 있는 행진은 **공지 일정 기준 예상 위치**를 지도에 군집(열지도 + 큰 원, 최소 반경 250 m)으로 보여 준다. 슬라이더를 옮기면 따라 움직인다(예: 11/9 국회대로 행진 11:30 국회 앞 → 13:15 마포대교~아현 → 15:00 광화문).
- 속도 = 경로 길이 ÷ 공지 시간(근거 없는 기본 속도 없음), 속도 ±20% 표본 21개.
- **표시만 한다.** 횡단보도 통제는 행진도 사건 전 구역·통제 시간 내내(태우 11/12 결정 — 군집 밖 횡단보도를 건너게 하던 버그를 고침: 같은 길이 106 m 로 건넘 → 879 m 로 돌아감).
- 운영 행진 6건에 모델 있음. 갈라진 행진(경로가 둘로 나뉨)은 모델 없음(정지 표시).

### 3.7 통제 제보 (T7.15 — 교수님 멘토링 T-A)
- 지도 오른쪽 **제보** 버튼 → 내 위치에서 가장 가까운 횡단보도(100 m 안)를 보여 주고 **막혔어요 / 열렸어요**.
- **기록만** 한다(경로·확신도에 안 씀). 사건 카드 근거에 "최근 1시간 제보 N건".
- 같은 기기·같은 횡단보도는 10분에 한 번.
- 현장 검증 도구: `scripts/field_checklist.py`(그 시간대 막힌다고 예측한 횡단보도 목록 CSV·GeoJSON), `scripts/field_compare.py`(현장 제보 vs 예측 → 맞음·더 막음·덜 막음, recall·precision). 11/14 현장 검증에 씀(`?mode=field` 로 열면 출처 field).

### 3.8 PWA · 통제 알림 (T7.7~T7.10, ADR-014)
- 홈 화면에 설치(manifest·서비스워커). iPhone 은 홈 화면에 추가한 뒤(iOS 16.4+).
- 시트 맨 아래 **통제 알림** 칸: 권한은 버튼으로만 → 브라우저 푸시 구독(계정 없음).
- **관심 지역**: 장소 카드의 ☆로 그 자리 반경 500 m 저장(최대 10곳), 내 위치를 켜면 그 근처(150 m 격자로 뭉개 3시간만).
- 관심 지역에 **새 통제가 생기거나 통제 중이 되면** 알림. 밤 22~07시에 생긴 것은 07시에 모아서. 알림을 누르면 그 사건 카드.
- 목록에서 빼기·알림 끄기. `/licenses#push` 에 저장하는 것 고지.

### 3.9 공개 데이터 피드 (T7.17 — 멘토링 T-C)

## 4. 동작 방식

### 4.1 흐름
1. **모으기(AI 워커, 상시):** 마라톤 코스·시각표, 경찰청 「오늘의 주요집회」 PDF, TOPIS 통제 공지 게시판, TOPIS 교통통제 지도(예정 통제), TOPIS 실시간 돌발(OA-13315).
2. **읽기(Claude):** 공지 문장 → `claude-haiku-5-5` tool use 구조화 출력 → 시간 창·장소 표현(spans)·구간(from/to/via/road)·통제 여부(impact)·종류. 프롬프트는 규칙서(`docs/data/notice_parser_rules_v2.md`)에서, 버전 관리(notice_v2). 확신도는 모델이 아니라 **규칙 표**로(README 확신도 표 그대로).
3. **위치 찾기(지명사전):** 이름 → 공공 데이터(교차로·역·횡단보도) + 카카오 기록. **모델은 좌표를 만들지 않는다.**
4. **막히는 횡단보도 고르기(BE):** 구간은 도로 그래프(국토부 표준노드링크) 최단경로 + 도로 등급별 폭(대로 25·로 15·길 8 m), 한 장소는 30 m, 마라톤은 코스 선. 사건마다 통제 구역 다각형도 만든다.
5. **상태 매기기:** 예정 → 통제 중 → 해제(+30분). '통제 중' 근거는 마라톤 시각표와 TOPIS 실시간 돌발뿐(공지 글만으로는 예정에 머문다).
6. **길찾기:** 서울 보행 네트워크 위 시간 의존 A*. 통제 중 = 제외, 창 안 예정(확신도 ≥ 0.7) = 횡단보도당 +300초, 확신도 < 0.7 = 지도에만.
7. **알림:** 워커가 60초마다 BE 에 발송 요청 → 사건 × 관심 지역 겹침 → 웹 푸시.

### 4.2 값들 (설정 그대로)
- 확신도: 길찾기에 쓰는 선 0.7, '통제 중' 선 0.8. 해제 후 30분 '정리 중'.
- 예정 통제 비용 300초(5분), 걷기 1.2 m/s, 계단 25 m·엘리베이터 40 m 가산, 그래프에 붙이는 거리 150 m.
- 이 값들의 근거·변경 이력은 ADR-011(A 라우터 비용) 등.

## 6. 구조 · 스택

| 부분 | 패키지 | 스택 |
|---|---|---|
| 계약 | `packages/contracts` (`naru_contracts`) | pydantic v2 — AI·BE 가 여기서만 데이터 정의를 가져옴, FE 타입은 여기서 생성 |
| AI 워커 | `packages/ai` | Python 3.12, anthropic SDK(`claude-haiku-5-5`, tool use), Shapely·pyproj, httpx. 독립 프로세스, BE 와 HTTP 로만 |
| 서버 | `packages/be` | Python 3.12, Flask 3 (MVC: controllers → views → models 한 방향), SQLAlchemy 2 + MySQL 8.4 + Alembic, NetworkX, Shapely STRtree, pywebpush |
| 화면 | `packages/fe` | Next.js(App Router), React 19, TypeScript strict, MapLibre GL JS, Context Provider + useReducer, PWA |

- 의존 방향과 "AI ↔ BE 직접 import 금지"는 import-linter 로 강제(계약 6개 유지).

- 규모(11/12): Python 약 12,200줄(테스트 제외), FE 약 8,500줄(테스트 제외), 커밋 557개(2026-11-01~).

## 7. 품질 · 검증

- **실데이터만:** 테스트·개발·시연 전부 실제 데이터 또는 실제 API·Claude 응답 기록으로. mock·fake·임의 좌표·손으로 친 공지를 쓰면 `make check` 가 실패한다(게이트 스크립트). Claude 응답은 전부 기록해 재생.
- **테스트(11/12):** Python 217 통과, FE 단위 202 통과(29 파일), Playwright e2e 53개 중 51 통과(실패 2개는 데이터 의존 — 원인 알려진 기존 것). iPhone 13 화면으로 매 기능 확인(스크린샷 §11).
- **공지 파서 평가(`docs/eval/notice_20261108_v2.md`, 실제 공지 34건·사람 라벨):** 전부 일치 — Claude 68%(95% CI 53~82%) vs 규칙 기준선 56%(38~74%). 필드별 Claude: 시간 창 97%, 종류 94%, impact 88%, 도로 86%, 구간 76%, impact 이유 100%.
- **버스 신호 실측(`docs/eval/bus_20261109.md`, 11/9 통제일):** 1개 차로 행진 셋에서 통제 시간 안 버스가 구간을 경로대로 124회 지나감(무정차 0) → 부분 차로 행진엔 버스 신호가 안 맞아 **확신도 보정 보류**(ADR-013), 전면 통제·마라톤만 기록.
- **링크 ID 대조(`docs/data/indirect_signals.md`):** 실시간 도시데이터 도로 링크 159개 = 표준노드링크와 159/159 같은 ID.
- **TOPIS 공지 아카이브(`docs/data/topis_archive.md`):** 공식 API 로 11년치 3,825건(2015-10-15~), 통제안내 1,483건 — 파서 평가 세트를 키울 재료. 사건 단위 돌발 이력의 공식 경로는 없음.
- **라우터 응답 시간:** 서울 전체 그래프에서 /route p95 수 ms 수준(T6.9 측정 p95 5.1 ms).

## 8. 개인정보

- 제보: 좌표는 요청 본문으로만 받아 가장 가까운 횡단보도를 찾은 뒤 **저장하지 않음**. 저장 = 횡단보도 ID·상태·시각·정확도·출처·기기 토큰의 sha256.
- 알림: 계정 없음. 저장 = 푸시 구독 주소·키, 관심 지역 좌표(반경). 내 위치는 켰을 때만, 150 m 격자로 뭉개 3시간 뒤 삭제. 관심 지역 이름(라벨)은 기기에만.
- 장소 ☆ 저장은 기기(localStorage)에만.

## 9. 운영 · 실행

- 서비스: `https://naru.antaewoo.com` — 홈서버, nginx → Next.js(3050) → Flask/gunicorn(5050), MySQL(Docker).
- systemd: `naru.service`(`make serve` — 마이그레이션·빌드·서버), `naru-worker.service`(`python -m naru_ai.worker --loop --live`). unit 파일은 `deploy/`.
- 워커 소스와 주기: 마라톤 코스 1회 · 공지 5분 · TOPIS 실시간 돌발 5분 · TOPIS 공지 게시판 10분 · TOPIS 교통통제 지도 10분 · 경찰청 PDF 폴더 1분 · 버스 위치 60초(전면 통제·마라톤 창만, 기록만) · 실시간 도시데이터 5분(활성 통제 근처만, 기록만) · 알림 발송 60초.
- 하루 상한: Claude live 파싱 200, 버스 900, 도시데이터 200. Claude 비용은 설계 추정 월 $1 미만(공지 50건/일).
- 로컬 실행(README 기존 절 유지): `make setup` → `make check`(키 없이 기록으로) → `make serve` → 워커. 필요한 `.env` 키 이름: `SEOUL_OPENDATA_KEY`, `DATA_GO_KR_KEY`, `KAKAO_REST_KEY`, `ANTHROPIC_API_KEY`, `NARU_INTERNAL_TOKEN`, `DATABASE_URL`, 알림은 `NARU_VAPID_PRIVATE_KEY`·`NARU_VAPID_SUBJECT`, FE 타일 `NEXT_PUBLIC_VWORLD_KEY`(선택). 값은 README 에 쓰지 않는다.
