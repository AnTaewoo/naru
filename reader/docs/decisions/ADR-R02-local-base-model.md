# ADR-R02 exp005 로컬 생성형 베이스 모델

상태: **제안** — R4.6 전에 태우 승인. exp003이 val에서 이미 ADR-R01 기준 동급이면 exp005 자체를 생략할 수 있다(태우 결정).

## 맥락
exp002·003(인코더 1억 파라미터급 + 미세조정)도 "로컬 + 사후학습"이다. exp005는 "생성형 로컬 LLM + LoRA"가 정규형까지 직접 내는 게 인코더 + 규칙 정규화기보다 나은지를 본다.
고르는 기준은 세 가지이고, 순서도 이렇다.
1. **라이선스** — Naru가 B2B 위젯(ADR-004, 제안)으로 가면 제3자 제공·온프렘 설치 조건이 걸린다. 연구용으로만 쓸지, 제품까지 갈지에 따라 후보가 갈린다
2. **VRAM** — R0.2 기록. 4bit QLoRA 기준으로 학습과 추론이 같은 GPU에 들어가야 한다
3. **한국어** — 모델 카드의 한국어 평가, 토크나이저가 한국어를 몇 토큰으로 쪼개는지(R4.6에서 train 문장으로 실측)

## 후보 (전부 R4.6 PLAN에서 모델 카드·라이선스 원문을 열어 다시 확인)
| 후보 | 크기 | 라이선스 (조사 시점, 원문 재확인) | 메모 |
|---|---|---|---|
| Kanana-2 instruct (카카오) | 1.3B / 3B | 자체 라이선스 — 제3자 제공·온프렘 제공에 조건이 있다고 조사됨 | 한국어 특화. 컨텍스트 32K. vLLM guided_json 사용 가능 |
| Qwen 계열 소형 (Alibaba) | 1.7B~4B급 | 크기마다 다르다 — Apache-2.0인 크기와 아닌 크기가 있으니 모델 카드 확인 | 다국어 |
| 그 밖 (EXAONE, Llama 소형 등) | | 비상업·커뮤니티 라이선스가 많다 — 확인 | |

## 결정 (제안)
- 연구(v0) 범위: 위 후보 중 **VRAM에 맞고 한국어 토큰 효율이 좋은 1개**로 exp005 1회. 라이선스는 "연구용 가능"이면 충분
- 제품(Naru) 채택은 별도: exp005가 판정에서 이겨도, 라이선스가 B2B를 막으면 ADR-007에서 다른 후보로 재측정 Task를 만든다
- 선택 근거(라이선스 원문 링크·확인일, VRAM 실측, 토큰 수)를 이 파일에 적는다
