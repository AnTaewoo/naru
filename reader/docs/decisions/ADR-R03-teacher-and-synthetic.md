# ADR-R03 교사 라벨·합성 데이터

상태: **승인 대기 (v0 금지는 CLAUDE.md §2.2로 이미 적용 중)** — v1 실험 여부는 PC-5에서 결정

## 맥락
작은 모델을 API 수준으로 끌어올리는 흔한 방법은 둘이다.
- **교사 라벨(distillation)**: 라벨 없는 문장 수천 개에 API로 라벨을 달아 작은 모델을 학습
- **합성·증강**: LLM으로 비슷한 문장을 만들거나 템플릿으로 찍어내 학습 데이터를 불림

둘 다 효과가 있을 수 있다. 하지만 v0에 섞으면 질문이 흐려진다.
- 교사 라벨로 학습한 모델과 교사(API)를 비교하면 "로컬이 API를 따라 했나"를 재는 셈이 된다. "사람 정답 기준으로 로컬이 API만큼 하나"가 아니다
- 합성 문장은 실제 공지 분포가 아니다. 합성으로 오른 점수는 실제 공지에서 재현된다는 보장이 없다
- 평가셋에 섞이면 회복할 수 없다

## 결정
**v0**
- 학습·평가 입력은 수집한 실제 문장뿐. 정답은 사람 라벨뿐
- LLM은 exp004(비교 대상)로만 쓴다. 그 출력은 학습 데이터·사전 주석·정답 어디에도 들어가지 않는다
- `scripts/check_no_fakes.sh`가 합성·증강 관련 이름을 막는다

**v1 후보 (PC-5에서 태우가 결정)**
- exp006 교사 라벨: train 기간 미라벨 풀에 API 라벨 → `data_version: v1-silver`로 분리 → 로컬 학습 → **사람 정답 val·test로만 평가**. 실버 데이터는 val·test 기간 문장을 절대 쓰지 않는다
- exp007 증강: 실제 train 문장의 지명만 사전의 다른 지명으로 바꾸는 식의 제한된 증강. 증강 문장은 학습에만, 비율을 바꿔 가며 곡선으로
- 둘 다 결과는 v0 결과와 별도 표로 보고
