# 라벨 가이드

상태: **v0 초안** — R3.1 파일럿(20문장, 2명) 뒤 v1로 확정. 확정 후 바꾸면 v1.1, 영향받는 라벨 범위를 기록한다.

## 0. 원칙
1. **보이는 것만 쓴다.** `text` + 앞뒤 문장 + `published_at`. 기사 원문을 찾아 읽지 않는다 (모델도 못 본다).
2. **장소·시간이면 라벨한다.** 통제 대상인지, 출발지인지, 행진 방향인지는 따지지 않는다 — 역할은 v1 관계 라벨.
3. **정규형은 사전에서 복사한다** (`data/gazetteer/browse.html`). 추측으로 만들지 않는다. 사전에 없으면 `NOGAZ:<표면형>`.
4. **확신이 없으면** 최선으로 라벨하고 `labeling/issues.md`에 sentence_id를 남긴다.
5. **수정은 Label Studio에서만.** export된 파일을 직접 고치지 않는다.

## 1. 경계 공통
- **조사 뺀다**: 에서 · 까지 · 부터(끝에 붙을 때) · 으로/로 · 와/과 · 을/를 · 의 · 에
- **방향·범위어 뺀다**: 방향 · 방면 · 일대 · 인근 · 주변 · 구간 · 일원
- **지점을 바꾸는 말은 넣는다(초안)**: 남단 · 북단 · 동측 · 서측 · 입구 → §6 Q3
- **기호 뺀다**: `~` `∼` `·` `(` `)` `,`
- **중첩 없음**: 가장 큰 단위 하나만. "세종대로사거리"는 INTERSECTION 하나 — 안의 "세종대로"를 ROAD로 따로 달지 않는다
- **반복 등장은 매번 단다** (Span-F1용. Norm-F1은 집합이라 영향 없다)

## 2. 태그별

### TIME
- 시각·날짜·기간 표현 하나를 한 스팬으로. 안쪽 연결어는 넣고 끝 조사는 뺀다
  - "오전 6시부터 9시 20분까지" → 스팬 `오전 6시부터 9시 20분`
  - "오후 1시 30분부터 시청교차로 방향으로 행진" → 스팬 `오후 1시 30분`
- 날짜와 시각이 붙어 있으면 한 스팬: "21일 오후 2시"
- "탄력적으로", "상황에 따라", "행사 종료 시까지" → TIME 아님
- "1시께", "1시경" → 시각 그대로

### ROAD
- 도로 이름. "세종대로와 종로" → ROAD 2개. "통일로·사직로·삼일로" → ROAD 3개
- 도로 이름 + 번지는 ADDRESS
- 차로·방향 표현은 빼고 이름만 ("세종대로 양방향" → `세종대로`)

### INTERSECTION
- `○○사거리` `○○삼거리` `○○오거리` `○○교차로` `○○로터리` `○○R`
- 역 이름 + R/교차로는 INTERSECTION: "삼각지역R", "교대역 교차로" (띄어 써도 한 스팬)
- 정규형은 사전 표기 그대로. 약칭("세종R")은 browse.html에서 찾는다

### POI
- 건물·광장·문·역·다리·공원: "숭례문", "대한문", "서울역", "숙대입구", "마포대교", "서울교", "광화문광장"
- 역 이름만 있으면 POI ("숙대입구" → 정규형 `숙대입구역`)
- 건물은 간판 명칭, 다리는 다리 이름

### ADDRESS
- 번지가 있는 주소만: "세종대로 172" → 정규형 `서울특별시 종로구 세종대로 172`처럼 전체 도로명주소
- 통제 공지에선 드물다

## 3. 정규형 규칙

| 태그 | 정규형 | 예 |
|---|---|---|
| TIME | ISO 8601 구간 `시작/끝`, 모르는 쪽 `..`, 분 단위, `+09:00` | "오후 1시 30분"(문맥상 22일, 끝 모름) → `2024-06-22T13:30+09:00/..` |
| | 끝만 있으면 `../끝` | "오후 5시까지" → `../<그날>T17:00+09:00` |
| | 날짜만 있으면 그날 하루 | "22일" → `2024-06-22T00:00+09:00/2024-06-23T00:00+09:00` (§6 Q6) |
| ROAD | 사전 도로명 | `세종대로` |
| INTERSECTION | 사전 교차로명 그대로 | browse.html에서 복사 |
| POI | 대표 명칭 | `숙대입구역` |
| ADDRESS | 전체 도로명주소 | |

날짜 정하는 순서:
1. 문장·앞뒤 문장에 날짜가 있으면 그것 ("22일" → `published_at`의 연·월 + 22일. 월이 바뀌는 경우 주의)
2. "오늘·내일·모레·이번 주말" → `published_at`(KST) 기준
3. 단서가 없으면 `published_at`의 날짜 — 모르는 걸 추측하지 않고, 같은 규칙을 모두가 똑같이 쓰기 위해서다

## 4. 예시 — train 기간의 실제 기사 표현
조사 때 본 표현이다. R3.1에서 수집된 원문 문장과 대조하고, 대조가 안 되면 지운다.
**val·test·test_ood 기간(2024-12 이후) 기사는 예시로 쓰지 않는다** — 주석자와 개발자가 평가 문장을 미리 보게 된다.

| 표현 (출처) | 라벨 |
|---|---|
| "세종대로 일대(숭례문∼시청교차로)" (SBS Biz, 2024-06-21) | ROAD `세종대로` · POI `숭례문` · INTERSECTION `시청교차로` — "일대", 괄호, `∼` 빠짐 |
| "오후 1시 30분부터 시청교차로 방향으로 행진" (같은 기사) | TIME `오후 1시 30분` · INTERSECTION `시청교차로` — "방향" 빠짐 |
| "서소문로와 한강대로를 통해 남영교차로까지" (같은 기사) | ROAD `서소문로` · ROAD `한강대로` · INTERSECTION `남영교차로` |
| "내일(22일)" (같은 기사) | TIME `내일(22일)` → 하루 구간 |
| "세종R·태평R·숭례문R … 통일로·사직로·삼일로" (아시아경제, 2022-11-18) | INTERSECTION 3 (정규형은 사전에서) · ROAD 3 |
| "교대역 교차로에서 서초역 교차로까지 오후 5시부터 탄력적으로" (한국경제, 2019-11-07) | INTERSECTION 2 · TIME `오후 5시` — "탄력적으로"는 TIME 아님 |
| "서울역~숙대입구~삼각지역R 구간을 반대 방향 2개 차로를 이용해" (뉴스토마토, 2022-06-16) | POI `서울역` · POI `숙대입구` · INTERSECTION `삼각지역R` — 차로·방향은 v1 SCOPE |

## 5. quality = drop
문장 추출이 깨졌거나(문장 중간이 잘림, 메뉴·광고 텍스트), 한국어가 아니거나, 같은 문장이 두 번 붙은 경우에만. 통제와 무관해 보여도 읽을 수 있는 문장이면 `ok`로 두고 라벨한다(장소가 없으면 스팬 0개).

## 6. 열린 질문 (R3.1에서 결정, 결정 내용과 날짜를 여기에)
