# ADR-001 첫 타깃은 마라톤, 집회·행진은 2단계
- 상태: 승인 (2026-11-01)
- 맥락: 집회와 마라톤 둘 다 도로 통제로 횡단보도가 막힌다. 어느 쪽을 먼저 할지.
- 결정: 마라톤(2027-03 서울국제마라톤 실증)을 먼저. 집회는 같은 엔진에 입력 소스만 추가.
- 근거: 주최측이 돈을 내는 B2B. 통제·해제 시각이 표로 사전 공개돼 파싱 신뢰도 높음. 선두·컷오프 페이스로 차단선 이동이 결정론적. 정치적 부담 없음.
- 결과: ROADMAP P2는 CourseIngestor 중심, NoticeParser(Claude API)는 P4로 — v0.5에서 11/16 경로에 포함.
