# ADR-002 실시간 인구 밀집도 데이터에 의존하지 않는다
- 상태: 승인 (2026-11-01)
- 맥락: 초기 아이디어는 통신사 밀집도 기반 우회. 50m 격자 원본은 계약상 비공개.
- 결정: 밀집도 없이 성립하는 설계. 집회·마라톤은 신고제라 통제 구간·시간이 사전에 존재한다.
- 근거: 없는 데이터를 전제로 한 기능은 데모가 안 된다. 서울 실시간 도시데이터(장소 단위)는 confidence 승격에만.
- 결과: CongestionWatcher는 라우팅에 관여하지 않는다. 계약이 생기면 같은 슬롯에 격자 데이터를 꽂는다.
