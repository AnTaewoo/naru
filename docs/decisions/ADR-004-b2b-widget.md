# ADR-004 판매 모델은 주최측·지자체 위젯 패키지
- 상태: 제안 (2026-11-01)
- 맥락: B2C 단독은 시장이 작고 네이버가 기능 하나로 흡수 가능.
- 결정: NAVITIME 迂回ルート検索パッケージ처럼 대회 공식 사이트에 규제 맵 + 경로 검색 위젯으로 제공. 종로구·KT 집회 알림톡의 다음 단계("알림 → 경로")로 포지셔닝.
- 근거: 주최측이 통제 안내 부담을 돈으로 바꿀 동기가 있다. TOPIS 공지 2유형(비상업)은 지자체 협약으로 푼다.
- 결과: FE는 임베드 가능한 위젯 형태를 염두. 상용화 전 서울시 협약 Task 필요.
