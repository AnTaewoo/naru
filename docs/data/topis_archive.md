## 3. 라벨 — 되는 것·안 되는 것
- **공지 → 구조화(시간·장소·종류)** 라벨: 11년치 공지 본문 3,825건(통제안내 1,483)이 있으니 파서 평가 세트(`cases_v1` 방식, 정답은 사람이)를 키울 재료는 충분하다. 1순위는 '통제일시'와 '통제구간'이 둘 다 있는 179건(표 형태가 일정), 2순위 '행진' 319건.
- **공지 → 실제 통제(언제 막혔나)** 라벨: 돌발 기록이 있는 11/7 이후만. 운영 DB 11/11 기준 공지·통제지도 후보 11건 중 돌발이 붙은 것 5건(`attach` — 같은 횡단보도·겹치는 시각), 돌발 사건 17건. 주말 집회가 있는 주에 수 건씩 쌓인다 — 11/14 현장 검증(T7.15 제보)까지 포함해도 수십 건 규모.
- 권장: ① 과거 공지로 파서 평가 세트를 늘리고(수동 라벨, 프롬프트 변경은 별도 승인) ② 공지↔돌발 짝은 운영 기록을 매주 누적해 `scripts/field_compare.py` 와 같은 틀로 센다. 공식 이력 API 를 기다리지 않는다.
